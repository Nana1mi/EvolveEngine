# G1-D4：同一输入、同一份权重，差异已在第 0 层投影内出现

复放 D3 已见的 4 个位置，在同一 BF16 激活和同一 packed Q8_0 权重上分别计算 whole 与 D3 split；主前向一律返回 whole。完整词表输出 **4/4 与 D3 E0 逐字节相同**，真实层执行事件 4/4，packed 权重摘要一致。单次容器 77 节点秒、结束无 GPU 计算进程。全矩阵中 split 与 whole 有约 **34.4–35.1%** 的输出元素不同，绝对差最大 **0.03125**。这把第一个已测差异定位到局部，而不只是下游或启动变化。

在预登记的 96 个独立 FP64 参考坐标上，实际 split/whole 的 BF16 输出 31 个不同；若仅对理想 FP64 两个部分积各舍入一次再合并，28 个不同。实际 whole、left、right 对应理想 BF16 参考分别有 54、53、50 个不同，实测差距与理想两段舍入的差距在 32/96 个坐标不相同。故**不能只凭两次 BF16 输出舍入解释结果**。实际 dispatcher 使用相同 GGUF 分支条件，参考不模拟 kernels 的内部激活量化或归约；此次不能分离内部量化、舍入和归约次序的贡献，也没有检验各层传播的因果幅度。

本轮没有换层，也未使用独立输入或改变 v0。下一步改用可解释的真实末端正控校准 G1；K 分块保留为开发负例/压力对照，不重标为优化收益。
