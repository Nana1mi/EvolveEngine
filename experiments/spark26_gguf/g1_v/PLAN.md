# G1-V-01：先导前独立合成验收（事前登记）

开发已经取得 E0/QKV-only 精确正控、真实计算故障和缺证的区分，以及两种取消阶段的混合请求。D5 的真实贪心 FP64 正控 21/32 非零且通过 v0。本实验只验先导前**合成质量门**；不是生产容忍度，不读密封 Q/T、不进入 Agent 会话，不以任何结果直接运行 P3/W。

- **新输入。** 32 个固定 V 位置，使用与 D2–D5 不同的随机种子和生成器（130/260 各半），此前未提交给引擎。要求至少 2 个 `E0 margin ≤ 0.125` 的自然近并列。不根据结果挑位置补抽。混合取消同样使用 V 新输入。
- **固定五次干净启动。** A0 未改动 E0 → A1 E0 重启 → B exact QKV-only → C D5 的 FP64 贪心正控 → D 新故障。A0/A1/B 必须全词表 32/32 逐字节相同、真实贪心 token 一致，且 B 有 QKV 路径证据。C 须执行真实采样 32/32，token 同 A0、至少一处非零数值差异。D：第 0 层第一个 V 输出通道（联合布局索引 2560）置零，其余层和输出不作此更改；不把已见的 Q 互换或 QKV 取负冒充新故障。D 实际执行后必须由 v0 拒绝；若发生漏检，留存并判本轮不通过，不能用源码违规判定把数值漏检偷改成通过。
- **不改 v0。** 每位置全词表 TV≤0.05，32 个位置至少 29 个 TV≤0.02，E0 margin≥1 时不翻转 Top-1。记录 KL、两侧 margin、Top-1、Top-10 与全词表最大差。离线删除一个通过的 C 行，再交同一规则，应判缺证不签收。C 的贪心 argmax 本就应相同，不假装见到合法的真实近并列翻转。
- **混合取消独立复核。** A0/A1/B 均使用 V-7 作 160 token 存活对照，与 V-6 的 128-token 目标分别在目标已生成 8、32 token 后取消；验证目标 abort、存活有实际交错且 ACK 后继续，并与 A0 独跑 160 token 完全相同。自然 EOS 仍以 r1 的另一个固定案例为证，不在此声称穷尽所有缓存策略。

冻结镜像、权重、启动参数与证据采样代码，各容器新建且无外网/独立缓存、节点锁排他。全部结束后离线审计，不重选阈值、样本或故障幅度。范围仅为所测条件下的实验室门禁，正式 W/业务质量契约与 P2 另行判断。
