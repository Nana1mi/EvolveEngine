# 共用 V3 Runner → 实际 Spark 开发评测：已验证

从共用 Linux Pi 1.5.2 Runner 的**真实 `write` 和工具调用**出发：在隔离 `.108` 给 Spark-X2.6-1.7B Q8_0 提交固定 QKV-only → 开发质检 → 四场景计时 → 用同一源码摘要显式交付。模型响应固定、无付费请求；没有执行自由优化或正式 W。独立观测容器只和候选共享无外网的网络命名空间，不共享文件、凭据、进程空间或回执写权限。

- 质检 **95.993 节点秒**：固定 32 个开发位置均齐证且与 E0 分布精确相同，4 项自然 EOS 对照一致，两档混合取消通过。源码、权重、46 个共同运行字段通过核验；符合 DEV 质检。
- 计时 **113.530 节点秒**：每场景 1 波热身、2 波测量，Scheduler 报告观察到四活动请求，W1/W2 98.10/96.10 tok/s、W3 约 2.284s TTFT、W4 113.77 tok/s。这是单候选的开发回显，**不是配对加速比**；合法交付由已签质量和 Pi 显式选择决定，不按这些速度排名。
