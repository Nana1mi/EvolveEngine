# V3 开发 RPC 实机连接

验证共用 Runner 收到真正的 Pi 工具调用，经可信宿主在隔离 GB10 执行真正的开发测量。这里不是开放优化，不用正式 Q/T，不计入自由先导。模型端仅固定合成响应，不让模型选择节点、测试或启动命令。候选范围为第一个登记的 Python Q8_0 文件；外层不替其修正或择优。

候选服务容器只持有固定基础镜像、只读权重和自己的补丁。独立可信观测容器进入候选隔离网络命名空间，只作为客户端；不共享进程、挂载、记录或 Docker socket。质量用既有开发前缀和已存 E0 锚点，全词表 v0、混合取消和真实自然 EOS；合法 QKV-only 作为事前固定正例。计时四场景沿用既有计量形状与探针，每场景 1 波热身、2 波计时。符合真实 DEV 合同才签收，不把设施缺证记成合法零收益。所有启动和超时均清理，无性能择优。
