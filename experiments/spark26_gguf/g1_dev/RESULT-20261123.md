# P1 / G1 开发门禁 r1：精确正控与故障反例

**结论：在登记的探针上，QKV-only 通过，故意错误的引擎被拒绝。不是完整 G1 签收。** 这里只验证门禁有能力区分这两种样例；不比较速度，不据此给所有近似优化设门槛。

## 启动与回放

- 2026-11-23 17:35:15–17:39:37（香港时间），隔离 GB10；E0-A、E0-B、QKV-only、故障控各启动一个新容器。首个启动到最后退出 262 秒；四次分别为 65、65、65、66 秒，中间另有 1 秒。不是 kernel 活跃时间，也不是 Agent 单次合法交付的成本。退出码 0，收尾快照无 GPU 计算进程。
- [事前登记](./PLAN.md)、[固定工件](./bundle.sha256)绑定镜像、模型摘要、补丁和探针；Q8_0 权重与模型附件启动前校验。46 个已投影运行时字段一致（不是完整环境认证）。上下文 8192、容量 16384、4 个运行槽，禁用 radix cache。只用合成输入，无付费模型、无密封 Q/T。故障是真实容器内在 QKV 精确快路径上将输出取负，不是修改裁判返回值。
- [机器回执](./receipt-r1-20261123.json)保留原始清单摘要、逐臂/逐项判定和统计；冻结 bundle 的 SHA-256 为 `5c0c6ee5797148fd5830cd69a7ac3b0367a626d707bb925699be8db568d26cf9`。本机原始证据位于 `%LOCALAPPDATA%/EvolveEngine/g1-dev-fJPjW8`；复核验证 12 份 JSONL、日志和启动前快照的 SHA-256，并检查运行顺序、模型校验和退出状态。这是受控测试记录，不是对任意自修改引擎的远程证明。

## 实测结果

| 检查 | E0 两次重启 / QKV-only | 故障引擎 |
|---|---|---|
| 自然 EOS；两条哨兵，各在取消前后查一次 | 每次均为 3 个 token（含 EOS=1），finish=`stop`、matched=1；同一输入上三次启动的输出完全一致 | 全部到 48 token 上限，finish=`length`；与同输入 E0 构成反例 |
| 指定请求在途取消 | 每次触发时已有 4 token；目标 ID 匹配、HTTP 200、终态 `abort`、7 个 token、`[DONE]` | 同样收到真正取消终态 |
| 取消前后再次生成 | 每条哨兵都与本引擎取消前及干净 E0 一致 | 前后同样错误；不能把这个错误归因于 KV 泄漏 |
| 全词表、相同前缀的下一位置 | 130 / 260 token 两个前缀，各自的 131,072 个 float32 log-prob 与 E0 逐字节相同 | 两个位置的分布、Top-1 均改变，见下表 |

| 合成前缀长度 | E0 / QKV Top-1 ID；第一、二名差（自然对数单位） | 故障 Top-1 ID | KL(E0‖故障)，nat | 最大绝对 log-prob 差 |
|---:|---|---:|---:|---:|
| 130 | 6529；10.516 | 83382 | 10.640 | 33.062 |
| 260 | 6511；3.258 | 83382 | 10.538 | 22.260 |

记录的是按词 ID 排序的**完整归一化 log-prob**，不是原始 logits，也不是 Top-K。各向量概率质量在 0.999999789–1.000000539；KL 按各自质量重新归一化。回放中 `|质量−1|<0.001` 只是捕获/格式检查，不是事前的模型误差阈值。这里的精确比较只针对声称精确等价的参考改动。旧合成性能预检的数据没有参与本轮裁决。

## 没有签收什么

1. 两个位置都不是近似平票；一个很大的故障容易检出。尚不能据此选择合法浮点漂移的通用 KL/Top-1 容忍带，或推断误放/误拒率。下一步在**已有开发负载，不加业务场景**中，先登记独立校准/验证位置、近并列分层、重复重启、已知合法的等价实现与幅度受控的错误样例；候选不参与定阈值。若合法与故障无法区分，报告边界而非调阈值到通过。
2. 取消终态与取消后的可观察输出已验证。未验证物理 KV 页全部归还、同时存在的另一个在途请求不受影响，或开启 prefix cache 的行为。不能把单次顺序取消说成全面的并发隔离证明。完整 G1 的其余覆盖（含 Q8_0 非 Torch 原生分配可见性）不因本次记录自动放行。
3. 门禁不以速度择优。完整合法但变慢的版本允许继承；确认错误才拒绝；缺回执不签收，原因单列。无 Controller 选最优 E/H。P2/P3 与正式 W 未由本次验收启动，也不冻结十轮预算。
