# G1-D5：真实贪心采样计算的高精度正控（事前登记）

D4 表明第 0 层 K 分块已在投影内产生差异，故不再试别的层。这里人为选择**正常的数学等价算法**验证开发数值规则能看到而不过拒非零差异，不向 logits 添加噪声、不改词表/权重、不伪造回执。仅在 CUDA FP32 logits、贪心、无替代 logprob logits 路径，使用实际 sampler 的 `FP64 max.indices` 选 token，并用稳定的 FP64 `log_softmax` 后回转原 dtype 返回同一分布。对非法/非审计路径不替代原有调用。承认这是末端舍入正控，不可代表中间层计算的微差，不计性能。它同时经过真正贪心决策与全词表归一化，方案不得用于仅改对外 Judge 报告。

只跑一次新鲜容器和已经看过的 D3 32 个开发前缀，沿用镜像、权重与参数，不开 G1-V。现有 D3 E0 manifest 固定为 anchor；从真实 sampler 路径逐位置绑定输入摘要、完整词表、代码哈希、执行的类型和生成 token。要求 32/32 有证，实际生成 token 与该分布 argmax 及 E0 的非并列 Top1 相同，且至少一个位置的全词表向量与 E0 不同。按原始 D3 screen v0 判，不调阈值：需在其范围内才称作真实末端低漂移正控。若不满足，保留真实反例，不根据结果选替代范围，不进行独立验收。

尚不预定业务容忍度。这是一个仅用于数值规则开发的可解释对照，不能用于推断 Engine 改动均可通行，不能签收 G1。
