# G1-D2 开发校准：运行前登记

仅限 spark-c3bc 隔离节点，单节点锁、清场、只读权重、无外网、每个容器 360s 硬上限。五次新进程 E0-A / E0-B / 精确 QKV 正控 B / C（相同 Q8_0 合同下的分块求和）/ D（输出的一对 Q 通道被错误交换）。不是性能测试、生产签收或正式盲验。模型 API、密封 Q/T、独立验证样本均不使用。

开发位置：按 `probe.py` 定死 32 个确定性合成前缀，交替 130、260 个普通 token，每个只取下一位置；不从任何候选结果中挑输入。分层使用 E0 的第一、二名自然对数概率差 m：近并列 m<=0.125（含严格平票），中间 0.125<m<1，较大 m>=1。哪一层为空就记录证据不足，不补抽到有利为止。同一输入在全部臂均采完整词表。记录全词表 KL(E0||X)、TV、Top-1 与 margin、E0 和 X 的 Top-10 并集内最大绝对 log-prob 差，全词表最大差；同值按 token ID 递增破平。KL/TV 用重新归一化后的概率，Top-10 差用接口返回的 log-prob。

正控 B 为原 QKV-only + 观测，不能把其带探针的源码摘要说成原版未插桩摘要。每次数字探针串行；一次请求一次独有 rid+输入摘要标记，只允许一个在途；在真实计算返回后，从运行进程记录该专属标记、M、模块路径与摘要。A 两次不修改计算。C 在原块和 Q/K/V 布局不动的前提下沿 K=2048 在 1024 分块；Q8_0 每 32 元素 34 字节，对应每半 1088 字节，两个原生乘积以 FP32 相加再转回 BF16。先验类别为数学等价的执行路径样例：允许中间舍入，但不预定其误差符合业务质量。D 不改变权重/vocab/其余 3070 通道，只交换 Q 的第 0、1 两列；先验语义错误，无论大小均不换故障。定义以代码为准，不向 logits 加噪声。

所有臂从同一镜像、模型哈希和配置启动，缓存目录在每个新容器内；已封装原生 kernel 随镜像固定，不声称重新编译了所有 CUDA 二进制。额外混合取消仅 E0-A/E0-B/B：独立长请求和存活请求同时流式运行，两次分别在目标生成至少 8/32 token 后定向取消；须有目标 abort 终态、存活请求取消前后有新 token 并正常完成、其输出与独跑相同。不能从此推断物理 KV 页释放。记录不中止的失败，缺证据不当成功。无计时排名、不重跑挑成功。

分析：先看 E0 重复与 B 命中，再看 C 能否出现非零漂移、D 是否有可分离的影响；比对多维分布和逐位置反例，不强行给出阈值。开发集上即使完全可分，也不叫独立验收。G1-V 需另行锁定判定器实现/阈值/不签收规则/独立样例机制及未使用位置，之后只运行一次。若重调，必须换独立验证批次。P2 只可并行做无 GPU 工程验证；P3/W 不启动。
