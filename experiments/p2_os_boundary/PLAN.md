# P2 / 外层隔离夹具

和 Windows 传输夹具同属合成验证；真实 Linux Pi 1.5.2，内网禁用、无 GPU/账户密钥/付费请求。目标是实证区分“私下可写”与“跨分叉不可提交”，并用文件系统与外进程共同构成边界。不能把脚本化策略称作 Agent 的自主性，也不把一次合成平台验收称为正式生产安全证明。

每个 role 使用独立容器和临时 HOME/cwd，输入固定只读，住在独立可信容器的 broker 通过每次独立 Unix socket 接受受限调用；Agent 无网络、无 Docker socket、无可信进程文件、非 root、无 capabilities，所用启动镜像按不可变 ID 核对。模型转发本地环回是 Agent 内的无信任传输层；鉴权、计量与回执在外面。所有尝试写新回执，失败保留，不自动重试。镜像用固定基镜像摘要和 npm 完整 lock 文件构建；不内置期望工具版本。先用同一外层 runner 验 T1/T2 的正反操作、T4 写入保护、T5 临时产物隔离，再验其他项所需的外层回执。若证据缺少，按原验收表不签收。
